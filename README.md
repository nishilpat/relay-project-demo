# Sales Relay Workflow Demo

This repo contains a home for my **Sales Relay** demo. The page presents a workflow overview for helping Account Executives turn customer conversations into clear follow-through with Claude-assisted execution. 

## On the page

- An overview of the Sales Relay workflow
- Two core surfaces: a **Customer Relay Link** and an **AE macOS Command Center**
- An embedded workflow demo video
- A few build learnings on working with Claude
- A link to the open-source repo

## Open-Source Note

This project is open-sourced and is itself built on top of the Clicky open-source project released under the MIT License.
